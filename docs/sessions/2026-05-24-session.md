## Notes
- **No `.receive(on: DispatchQueue.main)` on NSWorkspace sinks** — notifications already arrive on main; the runloop hop causes a one-frame blur-flash in PanicMode. This is documented in PanicModeManager and WorkspaceObserver.
- SourceKit shows false-positive "Cannot find X in scope" errors throughout — artifact of `PBXFileSystemSynchronizedRootGroup` auto-discovery. Actual `xcodebuild` always succeeds. Ignore SourceKit diagnostics on this project.
- Use `XCTestCase` with `@MainActor func test...` — NOT Swift Testing (crashes silently on this project).
- Scheme name is `VigilScreen` (not `VigilScreenTests`) for both build and test targets.
- Scrutinize verdict: **fix-then-ship** — two blockers will hit first real screen-share use.
